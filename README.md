# BLOOM patisserie 🌸

Sitio web moderno para una pastelería boutique.

## ✨ Concepto
Diseño elegante, minimalista y enfocado en una estética premium.

## 🚀 Características
- HTML semántico
- CSS moderno (Flexbox + Grid)
- Diseño responsive
- Formulario con Formspree
- Integración multimedia
- UI moderna con sombras, hover y tipografía refinada

## 🎨 Inspiración
Pastelerías boutique, diseño editorial y tiendas de lujo.
